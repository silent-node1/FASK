# FASK project page

This is a lightly edited copy of the
[Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

## Preview locally

From this folder, run:

```bash
python3 -m http.server 3000
```

Then open <http://localhost:3000>.

## Main files

- `index.html`: all page content and section order
- `static/css/fask.css`: the small set of FASK-specific styles
- `static/pdfs/paper.pdf`: the paper opened by the Paper button
- `static/images/`: pipeline and visualization-analysis figures
- `static/videos/`: simulation and real-world experiment videos

## Anonymous-review version

The page uses `Anonymous Authors`, contains no affiliation or venue label, and
sets `noindex, nofollow`. The public repository uses a clean anonymous commit
history. Images, videos, filenames, and document metadata should be reviewed
again whenever assets are replaced during peer review.
